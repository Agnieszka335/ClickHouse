## ✨ Key Features

| Feature | Description |
| :--- | :--- |
| **🔐 Authentication** | Secure login system for administrators. |
| **📦 Dynamic Catalog** | A clean, responsive interface to browse and filter available products. |
| **🛒 Shopping Cart** | Real-time cart functionality: add, remove, and manage items seamlessly. |
| **🛠️ Admin Panel (CMS)** | Dedicated management system to edit products and track inventory without code. |
| **⚡ High Performance** | Powered by Vite for near-instant load times and optimized assets. |

## 💻 Installation & Setup

Ensure you have [Node.js](https://nodejs.org/) installed on your computer.

1.  **Clone the repository**
    ```bash
    git clone [https://github.com/Agnieszka335/ClickHouse.git]
    ```
2.  **Navigate & Install**
    ```bash
    cd click-house
    npm install
    ```
3.  **Run Development Server**
    ```bash
    npm run dev
    ```
4.  **Production Build**
    ```bash
    npm run build
    ```
